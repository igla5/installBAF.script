ENGLISH

These scripts are designed for installation on fresh OS of *.deb family (Supported operating systems: Ubuntu: 22.04 LTS, 24.04 LTS (and compatible versions), Debian: 11 (Bullseye), 12 (Bookworm), 13 (Trixie), Linux Mint: 21.x, 22.x (automatically connected to Ubuntu bases)
Supported architecture: only amd64 (x86_64) !!!

1. To get started, it is advisable to create directories ~/install/installBAF/ and ~/install/installPostgre/ in the directory of the user on whose behalf the script will be run (sudo or root).

2. Download the BAF distribution in ~/install/installBAF/ and the PostgreSQL distribution in ~/install/installPostgre/ by required release for BAF from: https://dl.bas-soft.eu 

3. Download all scripts to  ~/install/ and read README_installPG.md and README_installBAF.md befor next step :)
4. Run the script as root or sudo user.

UKRAINE

Ці скрипти призначені для встановлення на свіжі ОС сімейства *.deb (Підтримувані операційні системи: Ubuntu: 22.04 LTS, 24.04 LTS (та сумісні версії), Debian: 11 (Bullseye), 12 (Bookworm), 13 (Trixie), Linux Mint: 21.x, 22.x (автоматично підключаються до баз Ubuntu)
Підтримувана архітектура: тільки amd64 (x86_64) !!!

1. Для початку роботи бажано створити каталоги ~/install/installBAF/ та ~/install/installPostgre/ в каталозі користувача, від імені якого буде виконуватися скрипт (sudo або root).

2. Завантажте дистрибутив BAF в ~/install/installBAF/ та дистрибутив PostgreSQL в ~/install/installPostgre/ з потрібним релізом для BAF з: https://dl.bas-soft.eu

3. Завантажте всі скрипти в ~/install/ та прочитайте README_installPG.md та README_installBAF.md перед наступним кроком :)
4. Запустіть скрипт від імені користувача root або sudo.
